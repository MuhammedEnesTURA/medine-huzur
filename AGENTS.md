# Repository rules

- Yalnız gerekli en küçük değişikliği yap.
- Mevcut davranışı gereksiz yere değiştirme.
- Güvenliği ve veri bütünlüğünü koru; secret, token veya parolaları kaynak koda yazma.
- Gereksiz dokümantasyon, rapor veya durum güncellemesi üretme; açıklamaları tekrarlama.
- Değişiklikle ilgili hedefli testleri çalıştır.
- Kullanıcı açıkça istemedikçe bağımsız refactor yapma.
- Token tasarrufu uğruna kaliteden ödün verme.
- Mevcut kodu anlamadan yeni bağımlılık veya mimari ekleme.
